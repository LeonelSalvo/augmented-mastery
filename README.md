# Maestría Aumentada / Augmented Mastery

**Comprender lo que construís. Crecer al hacerlo.**

La filosofía propone que delegar ejecución también pueda ser una oportunidad de desarrollar comprensión, criterio y capacidad de intervención. El manifiesto expresa ese propósito. **Auctor** es el método en desarrollo para llevarlo a la práctica. **Involut** es una primera aplicación a software, mantenida en un repositorio independiente.

Este repositorio contiene documentos, no la aplicación. No se afirma eficacia validada, certificación de maestría ni un resultado laboral garantizado. La posibilidad de comprender e intervenir se comprueba por obra y alcance; coincidir con una respuesta de IA no basta.
